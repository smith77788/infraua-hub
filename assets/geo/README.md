# ua-places.tsv — населені пункти України

Похідні дані з [GeoNames](https://www.geonames.org/) (дамп `UA.zip`,
завантажено 2026-10-21), ліцензія **CC BY 4.0** —
https://creativecommons.org/licenses/by/4.0/ . Атрибуція: «GeoNames, geonames.org».

Взято лише клас `P` (населені пункти), кириличні назви (українські й
російські форми — канали пишуть обома), координати з точністю до 0,001°
(~100 м) і код області GeoNames (admin1).

Формат рядка (TAB): `назва для показу`, `нормалізовані ключі через |`,
`широта`, `довгота`, `код області`. Нормалізація ключів — та сама, що в
`src/lib/gazetteer.ts` (і/и/ы/ї → и, є/э → е, ґ → г, й → и, без апострофів і
наголосів, дефіс → пробіл).

Покриття неповне (напр. «Баранів» на Рівненщині відсутній): чого немає в
довіднику, система не вгадує — допис із такою назвою просто не дає точки.
